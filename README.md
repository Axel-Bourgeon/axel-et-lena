# Axel & Léna

Application Android « plateforme » : petits jeux solo et à deux, outils, liens.

- **Télécharger l'APK** : https://github.com/Axel-Bourgeon/axel-et-lena/releases/latest/download/axel-et-lena.apk
- Le dossier `android/` est généré en CI (`flutter create`) puis adapté par `scripts/patch_android.py`.
- Chaque push sur `main` compile l'APK et publie une release.
